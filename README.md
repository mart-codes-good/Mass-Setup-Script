# Lector Sheet for Sunday Masses
This is a simple program that is a base template for the lector's sheet for sunday mass.
It is built in a way to make it simple to adjust values and names, titles, etc.
This should save time, as it is also build like a printer's interface.

```
Steps:
    You fill in the values in the template.
    You export/download the docx file for each sunday and vigil mass
    You email them to yourself so that you can easily print them

Todo: Add option to hopefully speak with printers so you can handle everything directly from here to save some more time
```
